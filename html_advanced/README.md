# HTML Advanced - Web Page Skeleton

## Overview
This project focuses on building the foundational semantic HTML structure of a web page based on a designer wireframe (Figma prototype). The objective is to construct a clean, modern, and accessible document layout using native HTML elements prior to applying CSS styles.

![Web Page Wireframe Structure](https://raw.githubusercontent.com/holbertonschool/Fix-My-Code-0x00/master/readme_header.png)

## Project Objectives
- Build semantic HTML structure using standard elements (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Implement nested grid layouts using container elements (`<div>`).
- Construct interactive components including navigation headers, card blocks, quotes, ratings, and embedded media structures.
- Ensure strict compliance with W3C HTML standard validation.

## Structure Summary
- **Header**: Navigation bar containing clickable logo and anchor links.
- **Banner**: Key call-to-action block and 4 feature highlights.
- **Quote**: Testimonial section featuring an image, quote block, and author attribution.
- **Videos**: Section displaying video cards with thumbnail, title, author details, and rating components.
- **Membership**: Option cards with imagery, text descriptions, and enrollment CTA buttons.
- **FAQ**: Two-row grid layout for frequently asked questions.
- **Footer**: Brand logo, social link icons, and copyright text.
